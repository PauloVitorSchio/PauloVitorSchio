## 🏗️ What I'm into right now

Thoughtful architecture. Not over-engineered, not under-thought. The kind where you look at the structure later and it still makes sense, because someone actually sat down and thought about it before writing the first line. That someone is ideally me, and I'm working on being better at it.

I like understanding systems at a level deeper than "it works." Not because it's always necessary, but because it usually is, eventually.
